# I-TEL Comunicaciones — sitio

Sitio estático. Home en `index.html` (copia de `ITEL Home v2.dc.html`).

## Deploy en Vercel
- Framework preset: **Other** (sin build).
- Output directory: `.` (raíz).
- No requiere build command.

## Estructura
- `index.html` — Home v2 (hero con video + secciones).
- `ITEL Contacto.dc.html`, `ITEL Preguntas.dc.html` — otras páginas.
- `hero-*.dc.html` — variantes de hero.
- `paraguay-map.html` — mapa embebido.
- `_ds/industry-.../` — design system Industry (CSS + bundle).
- `brand/`, `uploads/` — logos e imágenes.
- `support.js` — runtime del contenedor `.dc.html`.

## Pendientes
- `hero.mp4` en la raíz (lo provee el cliente).
- Datos de contacto (teléfono, WhatsApp, email) — marcados como "a completar" en Home y Contacto.
